# Crawler's Companion for iOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native SwiftUI app holding the whole companion offline, gated at the reader's chapter, that replaces its content when the site publishes newer.

**Architecture:** This repo gains an integer-keyed export (`content.json`, `manifest.json`, `gate-fixtures.json`), two feed routes and a JSON achievement endpoint. A sibling repo, `~/Sites/dcc-companion-ios`, holds a UI-free Swift package (`CompanionCore`) whose only public way to content is a position-scoped `Reader`, and an app target that is views and theme. The Swift gate is proven against fixtures the site's own gate code produces.

**Tech Stack:** Node 24 with `--experimental-strip-types`, Astro 6 endpoints; Swift 6, SwiftUI, Swift Testing, CryptoKit, XcodeGen 2.45, Xcode 27, iOS 26.

**Spec:** `docs/superpowers/specs/2026-10-04-ios-app-design.md`

## Global Constraints

- The gate is the product: no view may receive ungated content. `Content` and every stored field of `Library` other than `books` are `internal` to `CompanionCore`.
- `Frontier.of` equals `frontierOf`: book 0 → 0; chapter 0, or chapter ≥ the book's count → `book * 1000 + 999`; show everything → 9000.
- No reveal-tag string in any exported file; every gate value is an integer `key`.
- A beat's `kind` is never exported and never rendered. `use: Bool` is the only trace.
- Counts shown to a reader are of reached things, except Progress, which shows unsealed / total as the site does.
- No static copy in Swift sources may name an entity, alias or floor not safe at `1:1` (exemption: *Dungeon Crawler World*, as in `check-pages.mjs`).
- iOS 26.0 minimum; Swift 6 language mode; strict concurrency complete; warnings as errors; bundle id `innovativStudio.CrawlersCompanion`; team `TKA49YW68L`.
- Dark only. Colours and type from `src/styles/global.css`; fonts Barlow Condensed, Inconsolata, Open Sans.
- This repo's work happens on branch `ios-app`; nothing is pushed. `src/lib` imports name the `.ts` extension.
- Content text follows this repo's voice rules; the app adds no story text of its own beyond the back cover already printed on the front page.

## Review Focus

1. **A stored chapter past the book's end** (content update shortens a book, or a hand-edited default): treated as finished, never a crash or a frontier in the next book. → Task 5 test `chapterPastTheEndIsFinished`.
2. **A 200 that is not the feed** (captive-portal HTML, a truncated body): the active copy stays and the outcome is `.failed`. → Task 9 tests `htmlInsteadOfManifestChangesNothing`, `truncatedContentChangesNothing`.
3. **Search input that is not words** (`(`, `*`, `'s`, an emoji, 200 characters): no crash, no hit on a sealed name, an empty list where nothing starts a word. → Task 8 test `hostileQueriesAreInert`.
4. **An entry that is no longer met** while its page is on screen (the reader lowers their position, or an update removes it): `page(for:)` is `nil` and the view shows `*** No record ***`. → Task 6 test `unmetPageIsNil`; Task 12 view handles `nil`.
5. **A report that is only whitespace, or 180 unbroken characters**: the first is refused locally with *Nothing filed* and no request; the second is sent whole and the card wraps. → Task 10 test `blankReportIsRefusedLocally`, `deedIsCappedAt180Characters`; Task 16 wraps with `.fixedSize(horizontal: false, vertical: true)`.
